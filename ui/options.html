LLM 兜底（默认开启）

规则没命中、落进「待归类」的那一小撮才会发给模型 —— 不会外发整个书签列表。 没配 key 时自动跳过，不影响其余整理。默认服务商 DeepSeek。

扩展运行时读不到操作系统环境变量（MV3 里没有 process 对象）， 所以 key 由 python tools/inject_key.py 在加载前从环境变量读一次， 写入 src/llm-key.local.js。该文件已在 .gitignore 排除，打包时也不会包含。

DeepSeek 的模型名变动较频繁（deepseek-chat 已公告弃用）， 官方文档对「当前该用哪个名字」说法也不一致。若报 400/404， 换一个预设模型即可。
